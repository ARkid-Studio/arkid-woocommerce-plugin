# Brand sources

Vector sources for the WordPress.org icon and banner. Not shipped in the plugin
zip.

| File | What |
| --- | --- |
| `arkid-a.svg` | The "a" of the ARkid wordmark, used as the plugin icon. |
| `arkid-wordmark.svg` | The full "arkid" wordmark, used in the banner. |

Both are the official ARkid logo (brand navy `#132042`), taken from the
wordmark in `arkid-shopware-plugin/docs/logo.svg`, with the "CATALOGUE" line
dropped and the glyph paths re-based to a 0,0 origin. They draw in
`currentColor`, so the renderer sets the colour.
